This project renders company "logos" as CSS-generated initials badges
(see .logo-chip in css/style.css) instead of image files, so the site
works fully offline with zero broken image links.

Drop real logo files here (e.g. nexora.png) and reference them in an
<img> tag inside the .logo-chip elements in companies.js / home.js /
company-detail.js if you'd like to swap in actual images later.
